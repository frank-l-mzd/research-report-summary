# Worked example — 输入 → 输出

> **说明**：为演示输出框架，本示例使用一份**虚构的半导体设备公司业绩说明会纪要**（内容为示意，非真实事件）。
> 通过它可以看到 `research-report-summary` 的完整输出结构。

---

## 输入（示意）

一份 18 页的 Q3 业绩说明会问答纪要，包含管理层开场陈述、CFO 财务回顾、以及 11 个分析师提问。
涉及信息：订单结构、毛利率指引、海外大客户进展、研发投入节奏、明年产能规划、以及对行业周期的判断。

---

## 输出（技能产出）

# 【示例】某半导体设备公司 Q3 业绩说明会核心要点总结

## 一、会议概况

面向卖方分析师与机构投资人的季度业绩说明会，覆盖订单结构、毛利率、海外拓展、产能规划与行业周期判断。总裁出席，CFO 做财务回顾，共 11 轮问答。

## 二、核心观点（主题聚类）

| 维度 | 核心判断 |
|------|---------|
| **订单结构** | 先进制程占比首次过半（约 52%），成熟制程订单同比下滑，结构升级明显 |
| **毛利率指引** | 管理层给出明年 42%–44% 区间，理由是高毛利先进制程占比提升 + 零部件国产化率提高 |
| **海外拓展** | 已进入某海外头部客户量产验证阶段，但管理层拒绝给出时间表 |
| **研发节奏** | 研发费用率将维持在 14%–16%，不因短期业绩波动调整 |
| **产能规划** | 明年新增产线主要投向先进封装方向，预计产能同比 +60% |
| **行业周期** | 判断"本轮上行周期至少持续到明年下半年"，但承认成熟制程存在结构性过剩 |
| **风险自认** | 明确点名"出口管制政策变化"为最大不确定性 |

## 三、管理层关键原声论断

1. **"先进制程的订单能见度已经到明年三季度，成熟的反而看不清。"**
   —— 佐证结构分化，先进与成熟已不是同一条曲线。

2. **"我们不打算为了单季度数字去调研发。调了，明年就没东西卖了。"**
   —— 管理层对研发节奏的承诺，是判断长期竞争力的关键锚点。

3. **"海外客户这一块，请大家给我们一点时间，我做不好承诺，但我可以说测试已经通过了。"**
   —— 谨慎表述，说明订单落地存在时间风险，不宜线性外推。

4. **"成熟制程确实过剩了，这个我不否认。但我们的收入结构已经不太一样了。"**
   —— 罕见的坦诚表态，反而提升了其他数据点的可信度。

## 四、投资建议

### 积极信号 ✅

- **结构升级已被数据验证**：先进制程占比过半，是"量增"转为"质增"的明确信号，毛利率指引的上移有业务支撑而非口径调整
- **研发纪律强**：拒绝为单季业绩调整研发投入，说明管理层以多年周期为考核基准，有利于长期竞争力
- **先进封装产能大幅扩张**：+60% 的产能投向，与当前封装环节的高景气方向一致
- **管理层表达坦诚**：主动承认成熟制程过剩、拒绝给海外订单时间表——降低预期管理风险

### 风险关注 ⚠️

- **成熟制程拖累仍在**：先进制程的高增长可能被成熟制程的下滑部分对冲，总量增长或低于市场线性预期
- **海外订单存在时间不确定性**：验证通过 ≠ 订单落地，管理层明确不承诺时间表，不宜提前计入估值
- **政策风险被管理层自认**：出口管制变化是公司自身点名的最大不确定性，属于不可控外生变量
- **行业周期判断偏乐观**：管理层"上行至明年下半年"的判断带有立场，与"成熟制程过剩"的自述存在张力，需交叉验证

### 总体判断

**短期股价驱动力来自先进制程占比与毛利率指引的兑现，而非总量增速。**

本轮的核心变化是**收入结构**而非**收入规模**——建议跟踪三个可验证指标：
（1）先进制程订单占比是否持续提升；（2）海外客户从"验证通过"到"首笔订单"的时间间隔；（3）先进封装新产线的爬坡进度。

若三者同步兑现，毛利率指引 42%–44% 上沿可期；若海外订单持续无时间表，则市场将回归成熟制程下滑的定价逻辑。

## 这个示例演示了什么

| 技能要求 | 示例中的体现 |
|---------|-------------|
| 主题聚类而非顺序罗列 | 7 个主题横跨开场陈述、财务回顾与问答，按论证逻辑重组 |
| 原声为证 | 4 条引号内原句，均为承重结论 |
| 双向输出 | 4 条积极信号 + 4 条风险关注，无偏废 |
| 事实与推断分离 | 区分"验证通过"（事实）与"订单落地"（未发生） |
| 客观性质疑 | 对管理层乐观周期判断标注"带立场，需交叉验证" |
| 结论可执行 | 结尾给出 3 个可跟踪的验证指标，而非空泛结论 |
